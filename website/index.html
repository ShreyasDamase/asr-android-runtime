02 — CONNECTIVITY

Choose your
path to the robot.

DDS publishes to ROS 2 peers; TCP connects to ASR Studio. Choose the path for your workflow and configure its destination in the app or desktop tool.

ROS 2 MIDDLEWARE01

DDS

Publish directly to ROS 2 peers over Wi-Fi or USB tethering. DDS over USB is an IP network path.

WI-FIUSB TETHER↗
DESKTOP TELEMETRY02

TCP

Stream to ASR Studio over Wi-Fi or through an ADB reverse tunnel over USB.

WI-FIUSB / ADB↗

USB / ADB and USB tethering are separate connection methods. ASR does not currently provide a USB serial/UART transport.

04 — THE PERSON BEHIND ASR

Built for
robotics development.

ASR is an open-source project created and maintained by Shreyas Damase. It is dedicated to making Android sensor hardware practical to use in ROS 2 experiments, prototypes, and robotics projects.

The platform brings together the Android Runtime, ASR Studio, and ROS 2 tools so developers can move from device sensors to useful robot data with equipment they already have.
